# rental-task
Car and Bike rental task assignment using oops

The first step is an OOP coding assignment.

Build a Vehicle Rental System.

Create different vehicle types such as:
    Car
    Bike

Store common details like:
    Vehicle number
    Brand
    Rental price

Store vehicle-specific details:
    Car → number of seats
    Bike → engine capacity

Display vehicle details.
Calculate the rental amount based on the number of days.
Demonstrate your program with multiple vehicles.
